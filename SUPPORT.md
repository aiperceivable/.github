# Support

## Documentation first

- **[apcore documentation](https://apcore.aiperceivable.com/)** — concepts, guides, reference
- **[Getting started](https://apcore.aiperceivable.com/getting-started/)** — the shortest path to a working module
- **[Protocol specification](https://github.com/aiperceivable/apcore/blob/main/PROTOCOL_SPEC.md)** — normative behavior
- **[Conformance fixtures](https://github.com/aiperceivable/apcore/tree/main/conformance)** — the authoritative answer when documentation and an implementation disagree

## Asking a question

Use **[GitHub Discussions](https://github.com/aiperceivable/apcore/discussions)** for
questions, design proposals, and anything open-ended. Discussions are shared across the
ecosystem, so an answer there helps the next person with the same question.

Open an **issue** when you have something specific and actionable: a reproducible bug, a
concrete feature proposal, or two languages disagreeing on the same input.

## Which repository?

The ecosystem separates specifications from implementations. If you are unsure where your
question belongs, see the routing table in
[CONTRIBUTING.md](CONTRIBUTING.md#first-which-repository) — or just ask in Discussions and
say you are unsure.

## Security issues

Never in public. See [SECURITY.md](SECURITY.md).

## Response expectations

This is a maintainer-led open source project. Questions are answered on a best-effort
basis; issues and pull requests typically get a first response within 7 days. Security
reports are acknowledged within 48 hours.
